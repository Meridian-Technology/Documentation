## What we are building

Server-editable **consumer voice** with a local fallback. The binary always has enough language to render. A later sparse pack may replace strings. Platform pack is product-wide (All cities). Tenant pack is a city overlay.

```text
bundled pivotCopy.ts
  → disk cache (tenant + schemaVersion)
  → GET /pivot/config { copy: { revision, schemaVersion } }   // pointer only
  → GET /pivot/copy                                          // sparse entries
  → apply overlay, persist, bump generation
```

Public `GET /pivot/copy` returns the **already merged** sparse diff (platform ∪ tenant). The phone does one overlay apply. Failures keep the current tree.

| # | Decision | Choice |
| --- | --- | --- |
| 1 | First paint | Always bundled (or disk-hydrated) copy. Network is optional. |
| 2 | Public API | Keep `PIVOT_COPY` object + interpolator functions. Overlay replaces the template inside the leaf. |
| 3 | Interpolators | Named placeholders + ICU plural/select **only** where the current function branches on 1 vs N. Formatters like `.toLowerCase()` stay in code. |

| 8 | City switcher | Remap Voice by **label**, not raw `?page=`. Fleet Voice is page 1; city Voice is page 5. Other city pages have no fleet equivalent — drop to Overview. |
| 9 | Auth | Platform admins only. Same permission as crew config. |
| 10 | Publish model | Live PATCH + confirm modal. No draft/publish in v1. |
| 11 | Tokens | `brand.name`, `brand.cta`, `group.singular`, `group.plural` are first-class. Changing `group.singular` must ripple through tokenized strings. |

### Task 0.2 — Resolver: `s()`, `t()`, ICU

**Status:** `pending`

**Context:** Static leaves and interpolators need one lookup that returns the bundled fallback when no overlay exists.

**Instructions:**

1. Add a resolver module (suggested: `pivotCopyResolve.ts`).
2. `s(path, fallback: string): string` — overlay string or fallback.
3. `t(path, params, fallbackFn): string` — if an overlay template exists, format it; else `fallbackFn(params)`.
4. ICU MessageFormat for plural/select only. Simple `{city}` / `{group.singular}` interpolation is enough for non-branching keys.
5. Invalid templates must fall back to `fallbackFn` / bundled string. Never throw into UI.
6. Do not take a network dependency.

**Evaluation:**

- [ ] `s()` returns fallback with empty overlay
- [ ] `t()` formats a simple placeholder
- [ ] ICU plural `one` / `other` matches current `count === 1` branches for a fixture key
- [ ] Broken template returns fallback, no throw
- [ ] Tests do not import React Native

## Phase 1 — Overlay store and disk (still no production server)

The phone can apply a pack and survive a restart. Production still ships empty overlay.

### Task 1.1 — Module-level overlay store

**Status:** `pending`

**Context:** Leaves read at call time. A generation counter lets React re-render.

**Instructions:**

1. Add an overlay store: current entries map, tokens map, revision, schemaVersion, `applyPack`, `clearPack`, `getGeneration`, `subscribe`.
2. Resolver reads this store. `applyPack` ignores keys that fail `isRemoteCopyKey` and ignores packs with a **newer** `schemaVersion` than the binary (or a version the walker does not understand). Prefer: ignore unknown keys; if `schemaVersion > PIVOT_COPY_SCHEMA_VERSION`, still apply known keys and drop the rest.
3. Thread-safe enough for RN: apply is synchronous after JSON parse.

**Evaluation:**

- [ ] Apply + `s()` returns overlay

## When to execute

Remove deprecated routes **only after** install base on the pre-ritual store binary is negligible (target: ≥95% on ritual-capable build).

Check `config.mobile.minAppVersion` enforcement and store analytics before deleting routes.

## Rollback note

If ritual release causes issues:

1. **First:** revert `config.mobile.minAppVersion` below the broken store build (restores access for old binary).
2. **Second:** set `forceUpdate: false` if the update gate is blocking incorrectly.
3. **Last resort:** roll back the store binary — slow and affects all users.

Never reshape `GET /pivot/week-recap` in place — old binaries depend on the current response shape.
